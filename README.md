# PL Admin Platform — прототип

Интерактивный HTML-прототип админки по макетам.

## Запуск локально

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
cd prototype
python3 -m http.server 8080
```

Затем откройте http://localhost:8080

## Деплой на Vercel

Проект — статический (HTML/CSS/JS), сборка не нужна.

### Вариант 1: через Vercel CLI (быстрее всего)

```bash
cd prototype
npx vercel
```

При первом запуске CLI попросит войти в аккаунт Vercel (GitHub/GitLab/email). Дальше ответьте на вопросы:

- **Set up and deploy?** — Yes
- **Which scope?** — ваш аккаунт или команда
- **Link to existing project?** — No (первый раз)
- **Project name?** — например `pl-admin-prototype`
- **In which directory is your code located?** — `./`

После деплоя CLI выдаст публичный URL вида `https://pl-admin-prototype-xxx.vercel.app` — его можно отправить коллегам.

Продакшен-деплой (стабильный URL без preview-хеша):

```bash
npx vercel --prod
```

### Вариант 2: через GitHub + Vercel Dashboard

1. Создайте репозиторий и запушьте код.
2. Откройте [vercel.com/new](https://vercel.com/new) → **Import Git Repository**.
3. Выберите репозиторий, **Framework Preset: Other**, **Build Command** и **Output Directory** оставьте пустыми.
4. Нажмите **Deploy**.

Каждый push в `main` будет автоматически обновлять сайт.

## Разделы

В правой панели редактирования два отдельных раздела (вкладки):

1. **Настройка акции** — графовый редактор (триггер, награда), поля акции; для loyalty — привязка к VIP Club.
2. **Настройка бонуса** — атомарные бонусы: cash, FS, FB, кэшбэк, reload.
3. **VIP Club** — уровни с названием и порогом достижения. Не в акциях.

### Графовый редактор

- Добавьте **Триггер** или **Награду** кнопками над холстом.
- Соединение: выход **выполнен** триггера → **start** награды.
- Пример **Weekly VIP Cashback**: тип акции «Программа лояльности» → триггер «Ставка» → награда (кэшбэк).
- Перетаскивание нод — за заголовок; панорама холста — перетаскивание фона.
- Масштаб: кнопки − / + или Ctrl + колёсико мыши.

Чтобы открыть панель: кликните строку в таблице или кнопку «Добавить акцию».
