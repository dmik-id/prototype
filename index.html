    Триггер

    Доступны сохранённые триггеры: регистрация, прохождение идентификации, подписка на TG, скачивание PWA, депозит, ставка.

    Тип пакета
    Секторы колеса

    При каждом спине выбирается одна награда по заданным вероятностям. Сумма вероятностей должна быть 100%. Минимум одна строка с готовым бонусом FS / FB / бонусная игра / денежный.

    Пул наград

    При открытии кейса выбирается одна награда по заданным вероятностям. Сумма вероятностей должна быть 100%. Минимум одна строка с готовым бонусом FS / FB / бонусная игра / денежный.

    Бонусы в пакете

    Все перечисленные бонусы выдаются игроку одновременно. Ссылки только на сохранённые FS, FB, бонусную игру или денежный.
