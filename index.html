Добавление пользователей

    Кликните по ноде на схеме, чтобы настроить триггер или бонус.

    Триггер

    Доступны сохранённые триггеры: регистрация, подписка, подписка на TG, скачивание PWA, депозит, ставка.

    Два выхода: «выполнен» — триггер сработал в срок, «не выполнен» — время истекло. От каждого можно вести свою цепочку.

    Награда

    Доступны сохранённые бонусы: денежный, FS, FB, кэшбэк.

    Пакет наград

    Пакет задаёт набор наград (кэшбэк, FS, reload) для каждого уровня VIP.

    Формула начисления

    Фиксированный размер награды. В акции триггер (например, депозит) определяет, когда выдать бонус.

    Тип бонуса

    Wheel of Fortune (spin)

    Укажите количество выдаваемых спинов и настройки бонусов, которые могут выпасть в рамках спина.

    Формат: массив объектов. Минимум поля kind. Допустимые kind: cash, fs, fb, cashback, reload, vip_club_level.

    Не готов к добавлению в акцию

    Программа VIP Club

    Здесь задаётся, как игрок получает и удерживает уровень. Акции только выдают награды по уже присвоенному уровню.

    Справочник уровней

    ID уровня используется в пакетах наград.

    Правила получения уровня

    Минимальный порог за период оценки. Игроку присваивается максимальный уровень, чей порог выполнен.

    Для каждого уровня VIP добавьте строки наград: кэшбэк, FS, reload.
